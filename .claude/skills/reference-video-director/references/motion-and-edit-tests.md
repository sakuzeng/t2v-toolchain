# 运镜与剪辑判别测试

完成“可观察事实台账”后再使用本文件。标准术语与识别线索先查 [cinematography-knowledge.md](cinematography-knowledge.md)。这些测试用于降低人物动作、镜头运动和剪辑之间的混淆；任何单项证据都不能独立定案。

## 一、先判断镜头边界

- **硬切（Hard Cut）**：相邻帧的视点、尺度、背景或人物姿态发生不连续变化，且中间没有可追踪的模糊运动路径。
- **甩镜／甩镜转场（Whip-pan / Swish Transition）**：强方向性模糊跨越边界，可能掩盖切镜。必须检查边界前后数帧，不能直接认定为一镜到底。
- **前景擦除／遮挡转场（Foreground Wipe / Occlusion）**：手、衣袖或道具大面积遮住画面，可能隐藏切镜或重新构图。
- **动作匹配剪辑（Match on Action）**：切镜前后动作方向或姿态连续，但视点或构图改变。
- **连续重构图（Continuous Reframing）**：背景特征、人物几何结构和运动路径在整个变化中保持时间连续性。

## 二、区分镜头运动与人物运动

- 多数背景特征以一致方向运动、人物相对姿态变化很小时，才支持镜头运动。
- 背景保持稳定而肢体改变屏幕位置时，主要是人物动作。
- 前景和背景移动量不同时，先检查视差，再判断是旋转、平移还是环绕。
- 判断 Zoom 或 Dolly 必须有尺度变化证据。不能因为手在画面中上升，就直接写成 Tilt Up。
- 全画面光流会被近景人物、水面、衣料、烟雾和运动模糊污染，必须与稳定背景锚点交叉验证。

## 三、验证“跟踪”说法

用 `measure_tracks.py --track 标签:时间:x:y` 播种并读 `windows.json` 里的 `lk_tracks`，不要目测坐标。在多个时间点记录拟跟踪特征的标准化 `(x, y)` 位置。目标发生漂移时，最多只能描述为宽松跟随。只有轨迹确实近似静止，而且这种关系对构图有明确作用时，才能使用“屏幕锁定（screen-locked）”。绝不能从单帧中创造中央跟踪框。

## 四、检查动作与运镜的因果顺序

如果要声称“动作带动镜头”，必须验证以下发生顺序：

1. 作为动机的肢体或道具先进入画面或开始运动；
2. 构图随后产生响应；
3. 运镜过程中动作持续清楚可读；
4. 镜头最终落在预期揭示对象上。

如果镜头在动作可见前已经启动，应记录为独立运镜或保留多个解释，不能称为动作引导镜头。

## 五、转换成提示词

只描述证据能够支持的最低必要关系。除非坐标经过测量且确实重要，否则优先写“抬起的前臂与快速向上重构图配合，最终落在正脸”，不要写数值坐标。原片存在切镜时必须明确保留；不要在原片实际使用剪辑时，强迫生成模型模拟不必要的复杂长镜头。

## 六、测量值怎么读（`measure_tracks.py` 输出）

这些门槛是启发式，用来决定"能不能下结论"，不是最终真值。

| 量 | 位置 | 读法 |
|---|---|---|
| 候选切点 `spike_ratio` ≥ 2.5 且 `hist_corr` < 0.7 | `cuts.json` | `hard_cut_likely`，仍需看切点前后各 3 帧 |
| 邻域中值 ≥ 0.5 × 切点帧差 | `cuts.json` | `sustained_motion_not_cut`：是甩镜/大运动被场景分数误报，不是切 |
| `global_over_residual` > 1.5 | `windows.json.camera` | 整帧一致运动主导，镜头运动可信度高 |
| `global_over_residual` < 0.67 | 同上 | 主体运动主导；此时全局 dx/dy 不代表运镜 |
| `peak_global_pctW_s` 与 `peak_time` | 同上 | 运镜最快时刻；写 prompt 的速度词依据 |
| `holds` | 同上 | 能量低于窗口峰值 20% 且 ≥ 0.2 s 的停顿段；写"hold"时长的依据 |
| `person_visible_frac` < 0.6 且能量高 | `windows.json.scale_proxy.note` | 强运动模糊段：姿态/LK 不可用，只能目视描述，禁止任何锁定声明 |
| LK `tracked_frac` < 0.5 | `windows.json.lk_tracks` | 无法判定 |
| LK `range_xy` 最大值 < 0.05 | 同上 | `screen-locked` 候选（还要看它对构图是否重要） |
| LK `range_xy` 最大值 0.05–0.15 | 同上 | `loose tracking` 候选 |
| LK `range_xy` 最大值 ≥ 0.15 | 同上 | 非跟踪关系；只能写"动作与重构图配合" |
| `scale_proxy` 起→止 | 同上 | 按在画幅内的可见部位判景别，比"主体变大"可靠；画外关节会被模型幻觉出坐标，已用在画幅内过滤 |

光流用的是全局中值：强运动模糊段中值塌向 0、`dominance` 会误报"主体主导"，这时只采信 `energy`/`absdiff` 说明"有大运动"，方向靠密集帧里的背景锚点判断。
